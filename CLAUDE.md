DECISIONS.md is an index: before changing a feature, read its topic file in `docs/decisions/`. When a decision changes, update the topic file and its line in the index together.

When given a problem, always propose your plan to fix it and then wait for approval before proceeding with the implementation.

Prototypes are transient artifacts and do not need to be persisted in the repository.
